# Dom Bigode - Sistema de Agendamento e Gestão (SaaS)

Um sistema completo de agendamento e painel de gestão financeira (MVP) desenvolvido para a Barbearia Dom Bigode. 

## 🚀 Funcionalidades
- **Interface de Cliente:** Agendamento rápido e intuitivo, com seleção de serviços, profissionais e datas.
- **Login sem Fricção:** Identificação do cliente via WhatsApp e armazenamento local, sem necessidade de senhas complexas.
- **Dashboard Administrativo (SaaS):** Acesso restrito protegido por credenciais, contendo:
  - Faturamento consolidado (Hoje, 7 dias, 30 dias, Anual).
  - Desempenho e gestão individual de barbeiros.
  - Histórico de serviços concluídos e cancelados.
- **Gestão Dinâmica:** Criação e edição de serviços, membros da equipe e produtos de balcão direto pelo sistema.

## 🛠️ Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3 (Design Responsivo, CSS Variables, Flexbox/Grid).
- **Lógica e Dinamismo:** JavaScript Vanilla (ES6+).
- **Banco de Dados (MVP):** API Web Storage (`localStorage`) para persistência de dados no navegador.
- **UX/UI:** Aplicação de conceitos práticos de Interação Humano-Computador (IHC) para fluxos de conversão.
